Project scope/roadmap
1. take user input via a webcam or video file 
2. use OpenCV loop to parse and monitor video input
3. Use Roboflow hosted inference API to call inference on custom multi-class model to detect objects
4. Use Roboflow supervision to track objects across frames, define zones, compute violations and other metrics (define these later) 



inference video_path usage:
- call inference route from frontend, passing in path to uploaded video (from uploads/ folder)
- pass that path through call to inference service, use as video_path


python packages needed: opencv, supervision, inference, vidgear, flask
